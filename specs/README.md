# Carpeta de Especificaciones (Spec-Driven Development)

En este directorio residen las especificaciones funcionales y técnicas del sistema **SGTSITA**.

## Flujo de Trabajo
1. Cada nueva funcionalidad o cambio estructural debe tener su archivo numerado:
   - `001-nombre-funcionalidad.spec.md`
   - `002-modulo-facturacion.spec.md`
2. Para crear una nueva especificación, copia el archivo `template.spec.md`.
3. El agente de IA consultará esta carpeta antes de implementar cualquier código para garantizar que se cumplan los Criterios de Aceptación.
